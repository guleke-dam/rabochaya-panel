## 1. Обзор продукта

### 1.1 Проблема

В команде задачи, сроки и вопросы ведутся в разрозненных местах: в мессенджерах, в голове, в личных заметках. В результате:

- руководитель не видит полную картину загрузки и исполнения по каждому сотруднику;
- вопросы, заданные «в моменте», теряются и остаются без ответа;
- сроки по задачам просрочиваются без сигналов заранее;
- еженедельные справки (Excel/Word) лежат в папках, информация в них ищется вручную, ошибки в расчётах обнаруживаются поздно;
- подготовка сводной справки для руководства занимает часы ручной консолидации.

### 1.2 Решение

Единая рабочая панель в виде одного HTML-файла, открываемого в браузере, которая объединяет:

1. учёт задач с приоритетами, статусами, сроками и примечаниями по каждому сотруднику;
2. автоматические напоминания на неделю и сигналы о просрочке;
3. обзор команды для руководителя с объёмами и состоянием задач по сотрудникам;
4. журнал вопросов «в моменте» с фиксацией ответов;
5. динамику исполнения (графики) и журнал всех изменений;
6. библиотеку справок Excel/Word с быстрым поиском, автоматической проверкой расчётов и генерацией сводной справки по запросу.

### 1.3 Ключевые принципы

- **Ноль установки** — один файл, работает в любом современном браузере, без сервера и регистрации.
- **Ничего не теряется** — каждая задача, вопрос и изменение фиксируются с датой и автором.
- **Данные у пользователя** — хранение в localStorage браузера + экспорт/импорт JSON для резервных копий.
- **Скорость** — поиск и фильтры работают мгновенно по уже загруженным данным.

- Ежедневное открытие панели каждым сотрудником в начале дня (ритуал «утреннего обзора»).
- ≥ 90% задач имеют срок исполнения и приоритет.
- Журнал изменений растёт ежедневно (признак живого использования).

## 3. Пользователи и роли

### 3.1 Роли

| Роль | Описание | Ключевые сценарии |
|---|---|---|
| **Сотрудник** | Исполнитель задач | Утром видит свои задачи; добавляет новые; обновляет статус и % исполнения; задаёт вопросы; получает напоминания |
| **Руководитель** (👑) | Управляет командой | Видит обзор по каждому сотруднику; контролирует просрочки и приоритеты; отвечает на вопросы; формирует сводные справки; загружает файлы-справки |

### 3.2 Идентификация

- Пользователь выбирает себя из списка сотрудников в шапке («Работаю как…»).
- Роль «руководитель» назначается при добавлении сотрудника.
- Руководитель переключается между «Режимом сотрудника» и «Режимом руководителя».
- Система разграничения доступа отсутствует (локальное приложение, доверенная среда) — см. §9.

## 4. Функциональные требования (реализовано в v1.0)

### 4.1 Управление задачами

**FR-1. Карточка задачи** содержит поля: краткое наименование (обязательное), сотрудник, приоритет (Высокий/Средний/Низкий), статус (Не начата/В работе/Выполнена/На паузе/Отменена), срок исполнения (дата), % исполнения (0–100, шаг 5), примечания (свободный текст).

**FR-2.** Создание, редактирование, удаление задач через модальное окно; удаление — с подтверждением.

**FR-3. Быстрые действия в таблице:** смена статуса кнопкой ✓/↩, обновление % исполнения ползунком без открытия формы; при 100% задача автоматически переводится в «Выполнена» с фиксацией даты завершения; при снижении со 100% — возврат «В работе».

**FR-4. Индикация сроков:** подсветка «просрочено N дн.» (красная строка), «сегодня!», «завтра», «через N дн.» (жёлтая строка при ≤ 2 днях).

**FR-5. Сортировка списка:** активные перед выполненными → приоритет (высокий первым) → ближайший срок.

### 4.2 Фильтры и поиск

**FR-6.** Во всех списках задач — фильтры по статусу, приоритету, сотруднику (в общем списке), переключатель «скрыть выполненные».

**FR-7.** Сквозной текстовый поиск по наименованию и примечаниям с подсветкой совпадений (`<mark>`).

### 4.3 Вкладка «Мой день»

**FR-8.** Утренние сигналы: баннеры о просроченных задачах, задачах со сроком «сегодня», открытых вопросах сотрудника.

**FR-9.** Дашборд-карточки: активных / просрочено / срок сегодня / срок на неделе / выполнено за 7 дней / открытых вопросов.

**FR-10.** Форма «Задать вопрос» (тема, текст, привязка к задаче) и персональный блок напоминаний на 7 дней вперёд с разбивкой по дням.

### 4.4 Вкладка «Неделя»

**FR-11.** Календарная сетка Пн–Вс с карточками задач по дням, выделением текущего дня, листанием недель (пред./текущая/след.) и фильтром по сотруднику.

**FR-12.** Блок «Напоминания на неделю»: список просроченных и предстоящих сроков с указанием сотрудника, приоритета и % исполнения.

### 4.5 Вкладка «Обзор команды» (руководитель)

**FR-13.** Сводные карточки по команде: сотрудников / активных задач / просрочено / высокий приоритет / выполнено за 7 дней / вопросов без ответа.

**FR-14.** Раскрываемые блоки по каждому сотруднику: счётчики (активных/просрочено/выполнено/вопросов), прогресс-бар исполнения, полная таблица его задач, кнопка «+ Задача». Блоки с просрочками или вопросами раскрываются автоматически.

**FR-15.** Отдельные панели: «Просроченные задачи» (с переходом к карточке) и «Открытые вопросы в моменте» (с переходом к ответу).

**FR-16.** Общая таблица всех задач команды с фильтрами и поиском (см. FR-6, FR-7).

### 4.6 Вопросы

**FR-17.** Вопрос фиксируется с темой, текстом, автором, датой и необязательной привязкой к задаче.

**FR-18.** Ответ вносится прямо в карточке вопроса (руководителем или автором); хранится ответ, автор ответа и дата. Карточка меняет оформление на «ответ получен».

**FR-19.** Фильтры: открытые/с ответом/все, по сотруднику, поиск по тексту вопроса и ответа. Руководитель может удалять вопросы.

### 4.7 Динамика и журнал изменений

**FR-20.** График за 14 дней: три линии — создано задач, выполнено, активных на дату (ретроспективный расчёт); фильтр по сотруднику.

**FR-21.** Круговая диаграмма распределения всех задач по статусам.

**FR-22.** Журнал изменений: автоматическая запись каждого события (создание/редактирование/удаление задачи с перечнем изменённых полей, вопросы, ответы, загрузка справок) с датой-временем и автором; ёмкость 800 записей; поиск и фильтр по сотруднику.

### 4.8 Блок справок (Excel/Word)

**FR-23.** Загрузка файлов `.xlsx`, `.xls`, `.csv`, `.docx` (множественный выбор). Для Excel читаются все листы (включая формулы), для Word извлекается текст.

**FR-24.** Быстрый поиск по всем загруженным справкам: по слову/числу/фразе находятся строки листов Excel и фрагменты текста Word с указанием файла, листа, строки и подсветкой совпадения; показ первых 50 результатов.

**FR-25. Автоматическая проверка ошибок в расчётах:**
- пересчёт формул Excel (СУММ/SUM по диапазонам и спискам, СРЗНАЧ/AVERAGE, арифметика со ссылками на ячейки) и сверка с сохранённым значением;
- проверка «итоговых» строк: сумма статей слева vs указанный итог;
- проверка «итоговых» столбцов: сумма значений сверху vs итог;
- проверка арифметики в тексте Word (`a + b + … = c`);
- допуск округления 0,01; показ первых 60 расхождений с указанием файла, листа, ячейки и величины расхождения.

**FR-26.** Управление списком справок: иконка типа, дата загрузки, размер, листов/символов, бейдж «расчёты ок / ошибок N», повторная проверка всех файлов, скачивание сохранённого файла (если размер < 3,5 МБ), удаление, полная очистка блока.

### 4.9 Консолидация и справка по запросу

**FR-27.** Мастер формирования сводной справки: период (с/по), сотрудник или вся команда, составные разделы (чекбоксы): сводка по задачам, просрочки, открытые вопросы, статистика и расхождения по загруженным справкам, динамика за 7 дней.

**FR-28.** Форматы результата: показ на экране (HTML-отчёт), выгрузка в **Word (.docx)** (заголовки, таблицы, списки), выгрузка в **Excel (.xlsx)** (отдельные листы: Задачи, Просрочки, Вопросы, Справки, Расхождения, Динамика), копирование в буфер обмена.

### 4.10 Данные и персистентность

**FR-29.** Автосохранение всех изменений в `localStorage` с индикатором «✓ сохранено ЧЧ:ММ» в шапке.

**FR-30.** Экспорт полного состояния в JSON (резервная копия / перенос) и импорт с валидацией формата и подтверждением замены.

**FR-31.** Сотрудники: добавление через интерфейс (ФИО, роль), демо-набор при первом запуске, поле `active` для архивации.

## 5. Пользовательские сценарии (основные потоки)

### 5.1 Утро сотрудника

1. Открывает панель → выбран его профиль (запоминается).
2. Видит баннеры: «Просрочено 1», «Срок сегодня: отчёт по кассе».
3. Обновляет вчерашние задачи: двигает ползунки % , отмечает завершённые ✓.
4. Добавляет новые задачи дня с приоритетом и сроком.
5. Столкнулся с неясностью → задаёт вопрос с привязкой к задаче → вопрос не теряется.

### 5.2 Утро руководителя

1. Открывает панель → «👑 Режим руководителя» → вкладка «Обзор команды».
2. Видит карточки: активных 8, просрочено 2, вопросов без ответа 1.
3. Раскрывает блоки сотрудников с просрочками → открывает задачи → переназначает/комментирует.
4. Отвечает на открытые вопросы во вкладке «Вопросы».
5. Просит панель: «Сформировать справку за неделю» → получает .docx для вышестоящего руководства.

### 5.3 Работа со справками

1. В понедельник сотрудник загружает еженедельные справки (.xlsx, .docx) пачкой.
2. Панель мгновенно показывает: «найдено расхождений: 3» → руководитель видит ячейки и величины расхождений до подписания.
3. Через день нужен показатель: поиск «выручка» → найденные строки с листом и строкой за секунды.
4. По запросу руководства — консолидированная справка .xlsx с листами «Задачи», «Просрочки», «Расхождения».

## 6. Нефункциональные требования

| Категория | Требование |
|---|---|
| **Платформа** | Любой современный браузер (Chrome/Edge/Firefox), desktop-first; адаптивная вёрстка до ~900 px |
| **Производительность** | Мгновенная фильтрация/поиск по ≤ 1 000 задач и ≤ 50 загруженным справкам; рендер < 100 мс |
| **Хранение** | localStorage (лимит ~5–10 МБ); файлы справок сохраняются для скачивания только до 3,5 МБ, остальное — индекс (текст и структура) |
| **Офлайн** | Вся логика работает офлайн; интернет нужен при первом открытии для CDN-библиотек (Chart.js, SheetJS, Mammoth, docx.js, FileSaver) |
| **Надёжность** | Автосохранение при каждом изменении; экспорт/импорт JSON как средство резервного копирования |
| **Язык** | Русский интерфейс; поддержка формул СУММ/СРЗНАЧ и SUM/AVERAGE |
| **Безопасность** | Данные не покидают устройство; экранирование пользовательского ввода (XSS-защита); безопасный вычислитель формул (whitelist символов, без `eval` произвольного кода) |
| **Лицензии библиотек** | Chart.js, SheetJS (xlsx), Mammoth.js, docx.js, FileSaver.js — MIT/Apache (permissive) |

## 7. Техническая архитектура (as-built)

### 7.1 Состав

Один файл `ai-assistant-panel.html` (~90 КБ): HTML-разметка, CSS, JavaScript в одном документе.

### 7.2 Модель данных

```json
{
  "employees": [{ "id", "name", "role": "manager|employee", "active" }],
  "tasks":     [{ "id", "title", "emp", "priority", "status", "due",
                  "progress": 0-100, "note", "created", "doneAt" }],
  "questions": [{ "id", "emp", "topic", "text", "taskId", "date",
                  "answer", "answeredBy", "answerDate" }],
  "docs":      [{ "id", "name", "type": "excel|word", "size", "date",
                  "sheets": [{ "name", "rows": [[...]] }],
                  "text", "errors": [{ "doc", "sheet", "cell", "kind", "desc" }],
                  "base64" }],
  "history":   [{ "ts", "emp", "text" }]
}
```

### 7.3 Зависимости (CDN)

| Библиотека | Назначение |
|---|---|
| Chart.js 4.5 | Графики динамики и статусов |
| SheetJS (xlsx) 0.18.5 | Чтение/запись Excel, чтение формул |
| Mammoth.js 1.6 | Извлечение текста из .docx |
| docx.js 8.5 | Генерация сводной справки .docx |
| FileSaver.js 2.0 | Скачивание файлов из браузера |

### 7.4 Ключевые алгоритмы

- **Аудит Excel**: индексация ячеек → поиск формул (объект `{f, v}`) → безопасный вычислитель (SUM/AVERAGE по диапазонам, ссылки A1, арифметика, whitelist `[0-9+\-*/().]`) → сверка с кэшированным значением; эвристики «итоговых» строк/столбцов по маркерам «итог|всего|сумма».
- **Аудит Word**: регулярное выражение цепочек `a + b + … = c` с нормализацией разделителей (пробелы, запятые) и проверкой суммы.
- **Напоминания**: сравнение `due` с `today` в целых днях; классы `overdue` (<0), `donesoon` (≤2).

## 8. Ограничения текущей версии (честно)

1. **Один компьютер, один браузер**: данные в localStorage — не синхронизируются между сотрудниками; совместная работа только через экспорт/импорт JSON или поочерёдно на общем ПК.
2. **Нет разграничения прав**: любой может выбрать любой профиль и режим руководителя (доверенная среда).
3. **Нет push-уведомлений**: напоминания видны только внутри панели при её открытии; закрытый браузер не пришлёт сигнал.
4. **Загруженные справки живут в браузере**: очистка localStorage удалит их; большие файлы (>3,5 МБ) нельзя скачать обратно (хранится только индекс).
5. **Проверка расчётов — эвристическая**: ловит расхождения итогов и формулы базовых видов; не заменяет полноценный аудит сложных моделей (массивные формулы, макросы, сводные таблицы — вне объёма).
6. **Одновалютность/без шаблонов**: нет валидации структуры «правильной» еженедельной справки.

## 9. Дорожная карта

### R1 — Совместная работа (приоритет: высокий)

- Серверное хранение (например, лёгкий backend + SQLite/PostgreSQL) и общая база задач для всей команды.
- Учётные записи и роли (руководитель/сотрудник/наблюдатель) с реальным контролем доступа.
- Живое обновление между пользователями (WebSocket/polling), индикатор «кто сейчас редактирует».

### R2 — Каналы напоминаний

- Уведомления в Telegram-бот/на e-mail: «сегодня срок по N задачам», еженедельный дайджест руководителю в пятницу.
- Настраиваемые правила: за 3 дня до срока, при просрочке, при новом вопросе.

### R3 — Углубление работы со справками

- Шаблоны еженедельных справок: валидация структуры (обязательные листы/колонки), сравнение с прошлой неделей (динамика показателей, отклонения > X%).
- Консолидация числовых показателей из разных файлов в единый реестр (авто-джойн по ключевым строкам).
- Поддержка PDF-справок (OCR для сканов).

### R4 — Аналитика

- Скорость исполнения (velocity) по сотрудникам, прогноз срыва сроков по % исполнения и остатку дней.
- Heatmap загрузки команды, длительность цикла задачи от создания до выполнения.

### R5 — Удобство

- Мобильная версия (PWA) для обновления статуса «с телефона».
- Импорт задач из Excel/CSV, интеграция с календарём (.ics по срокам).
- Тёмная тема, печать отчётов, настраиваемые статусы и приоритеты.
